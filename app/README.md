# Calculator App 

A responsive, feature-rich Android calculator application built with Kotlin and Jetpack UI components. Standard arithmetic operations paired with additional user-focused enhancements.

---

## 🚀 Key Features & Enhancements

### Baseline Functionality
- **Standard Calculations**: Supports basic operations (+, -, x , / ), decimals, clear (`C`), and backspace (`⌫`).
- **Error Handling**: Gracefully handles divide-by-zero errors without crashing.

### Enhanced Features (Implemented 2/2)
1. **Backspace Button**: Allows quick correction by removing the last entered digit without clearing the entire calculation.
2. **Sign Change (+/-) Toggle**: Toggles the current number between positive and negative values during active calculations.
